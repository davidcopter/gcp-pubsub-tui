# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-02-06

### Added
- Interactive TUI for Google Cloud Pub/Sub subscriptions
- Chat-style message display with scrolling
- Auto-acknowledgment support for messages
- JSON pretty printing for message payloads
- Setup form for subscription configuration
- Cross-platform support (Linux, macOS, Windows)
- `--version` flag to display version information
